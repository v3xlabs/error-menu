# Error Menu

a lightweight static dynamic upside down and right up again analaysis tool for git.

## Features

- [ ] static analysis
- [ ] secrets & configuration
- [ ] llm assisted review
- [ ] formal verification
- [ ] unified findings
- [ ] historical tracking
- [ ] reporting & alerts

## Usage

Error-menu is a simple tool that can be setup to watch repositories, github orgs, forks, branches, and more.
It automatically pulls in reviewable work, performs a variety of analysis methods, compares diffs, and previously reported on issues.

It can be run in stealth, for a single user, or when given git forge credentials, for a team, with reviews and comments auto posted on PR's and commits.
